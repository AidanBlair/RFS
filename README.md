# RFS

## Overview

A C++ library for Random Finite Set (RFS)-based multi-object tracking. 

## Features

Current features include:
- LMB filter implementation (for a single sensor)
- Birth, Motion, Detection and Measurement models
- OSPA and OSPA(2) metrics

## Requirements

- **C++:** C++20-compatible compiler.
- **CMake:** Version 3.20 or later.
- **Eigen:** Version 3.4.0.
- **nlohmann/json:** Version 3.11.3.

Eigen and nlohmann/json are downloaded automatically by CMake using `FetchContent`, separate manual installation is not normally required.

The project has been developed using Visual Studio 2022 on Windows 10.

## Installation and Build

### 1. Clone the repository

```bash
git clone https://github.com/AidanBlair/RFS.git
cd RFS
```

### 2. Configure the project

```bash
cmake -S . -B build
```

CMake configures the project and downloads the required dependencies.

### 3. Build the library and examples

```bash
cmake --build build --config Release
```

This builds the library and the example targets configured by the project.

### 4. Run the example

Run the `lmb_demo` executable generated by the build. Its exact location depends on your operating system, generator, and build configuration.

The example uses the supplied example ground-truth dataset.

## Example

The example program in *examples/lmb_demo.cpp* demonstrates multi-object tracking using the LMB filter.

It uses *examples/data/test_ground_truth.json*, an example scenario where 11 targets move over 50 time steps, including target deaths. Average OSPA and OSPA(2) errors (including localization and cardinality components) over the evaluated time steps are reported.

To run the example, execute the generated *lmb_demo* executable. The exact executable path depends on your build configuration and generator.
